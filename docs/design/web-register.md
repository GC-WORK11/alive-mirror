# web register — v13 (cognition.com × devin.ai)

Extracted live from https://cognition.com and https://devin.ai, 2026-10-08.
Owner law: 'same fonts same no navbar same blogging style same to the last
line or border same to the same font size texture.'

## Type

- **Heading/UI**: `NB International Pro` — proprietary Neubau grotesque,
  weights 400/500/700. NOT freely licensable → **fallback stack**
  `-apple-system, 'Helvetica Neue', Helvetica, Inter, 'Segoe UI', Roboto,
  sans-serif` (SF Pro / Helvetica Now class — the same neutral-grotesque
  family visually; zero-cost, zero-download, chosen for the zero-budget law).
- **Body prose**: `STK Bureau Serif` — proprietary text serif.
  Fallback: **Georgia, 'Times New Roman', serif** — same register for long
  reading lines. Used ONLY for the purpose/story lines, not for labels.
- **Mono micro-labels**: `GeistMono` (12px, tracking −0.12px) →
  `ui-monospace, 'SF Mono', Menlo, monospace`.

### Scale (measured)

| role | size | leading | weight | notes |
|---|---|---|---|---|
| section heading | 15–16px | 1.3 | 400–500 | serif body font, NOT bold sans |
| hero/statement line | 24→36px | 1.1–1.2 | 400 | tracking −0.02em, max-width ~16ch |
| body | 15px | 1.5 | 400 | serif |
| micro-label/index | 10–12px | 1.5 | 400 | mono, small, quiet |
| feature shot captions | 13–14px | 1.5 | 400 | devin.ai register |

Nothing is bold-black display. Everything is SMALL — the texture is
'blog post', not 'marketing'.

## Color

- background: `#F7F6F5` (warm paper)
- ink/primary: `#000`
- secondary text: `rgba(25,25,25,.56)` (#1919198f)
- accent: `#20F` links only — **we keep forest for air-meaning**, and band
  colors where they mean AQI
- borders: 1px `rgba(0,0,0,.10–.15)` hairline rules between sections/rows
- buttons: 32px h, 1px solid ink border, 10px px, 15px, no fill, no shadow;
  or `#191919` fill for the single primary. Never pills with shadows.

## Layout

- NO navbar. Top-left: tiny wordmark + text links stacked (home · field ·
  delhi · community), 10–15px, plain.
- Left rail: margin index `01` `02` `03` per section, 10px mono, aligned
  to section top. Content starts one column in — wide left gutter
  (~20–25% of the centered measure).
- Center measure: ~640–680px content column inside a ~1200px grid; padding
  20px mobile / 64px desktop. Sections separated by hairline rules +
  ~88–180px of air, never cards.
- Numbered features (devin.ai): `01` + one small serif heading + one prose
  line + the product shot below/beside, raw — a slim phone frame is OK for
  app captures (it IS the object), no card behind it.
- 'Recently shipped' list: two-column small rows — date | item — hairline
  separated, 13px.
- Footer: small link columns (product · legal · connect), 13px, hairline
  top rule; giant ghost wordmark allowed as the ONE expressive object.

## Absolute bans (this register)

- boxes, cards, bordered panels, capsules, chips, shadows, gradients on
  surfaces, floating pill navbars
- all-caps tracked lettering anywhere
- bold-black marketing display type — the texture is quiet and precise
- any download/cta ask (owner law), any github/repo link (owner law)
